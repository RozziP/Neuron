# Neuron v0.1.6

Separate profiles and macros for each mouse, expanded experimental Razer support, and a Redragon M990-WL driver.

## Download and upgrade

Download **Neuron-Setup-0.1.6-x64.exe**, save any pending edits, quit Neuron from its tray menu, and run the installer. Existing installations reuse their folder and retain saved profiles, macros, mouse selections, and original-mouse backups. Launch Neuron from the Start menu afterward. No manual uninstall, Node.js installation, or administrator access is needed. The installer is unsigned; `SHA256SUMS.txt` contains its checksum.

Existing profiles migrate into separate mouse workspaces. Each workspace receives a copy of the previous shared macro library, and the legacy profile file is retained. Back up `%APPDATA%/Neuron` before manually downgrading to an older release, which does not understand the new workspace storage.

## Changes

- Adds a persistent **Your devices** selector with separate profiles and macro libraries for each mouse, including multiple mice of the same model. Game switching and DPI controls target the selected mouse.
- Expands the Razer catalog to 131 connection identities: 123 experimental USB/receiver candidates and eight Bluetooth identities for offline profiles. Model-specific side, body, and wheel layouts replace the generic Naga layout.
- Adds experimental Redragon M990-WL support for 16 side buttons, keyboard combinations, Neuron macro triggers, standard mouse buttons, disabled assignments, and battery readings. The driver verifies the mouse behind its shared receiver before enabling writes and backs up and verifies changed mappings.
- Refreshes button mapping controls, form styling, device identity details, and update status presentation.
- Prevents keyboard focus handlers from running before the UI has initialized.
- Extends automated coverage for workspace isolation, device selection, Razer layouts, and Redragon protocol behavior.

## Hardware limitations

Only Trinity has been physically tested among the Razer adapters. Other Razer mappings are experimental best guesses and require validation on their actual devices. Bluetooth configuration and non-Trinity DPI controls remain unavailable.

For Redragon M990-WL, wireless side-button-1 press/release and exact restoration were physically tested during development. Other positions and assignment types remain experimental. Wired transport has not been physically tested; top-button remapping, DPI configuration, and Bluetooth configuration are not supported. Keep the mouse awake and close its vendor configuration software before applying mappings.

## Validation

All 114 automated tests and 302 Razer layout checks passed. Desktop, workspace, simulated DPI, and Redragon smoke checks passed. Native key injection was skipped when another application held foreground focus; physical device access in these checks was read-only. The preceding local package update preserved all 12 saved JSON files, matched the built application archive, and reopened with both attached mice detected.
