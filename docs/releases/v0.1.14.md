# Neuron v0.1.14

Save a set of Naga Trinity bindings to return to after quitting, and download updates while continuing to use Neuron.

## Keep your Trinity bindings

Choose a profile in **Button mapping** and click **Save onboard**. Neuron saves and verifies its bindings, then remembers that set for quitting, update installation, and switching to another mouse. Temporary profile changes and automatic game switching leave the saved set intact.

Key shortcuts, modifiers, mouse buttons, Original, and disabled assignments are supported. Replace assigned macros first because playback requires Neuron running. DPI is unchanged. **Save onboard** again replaces the saved set; **Devices → Restore original** restores the first backed-up settings and clears it.

This feature is limited to Naga Trinity. It does not manage multiple hardware profile slots, and persistence after unplugging or power cycling remains unverified.

## Download now, restart when ready

**Download v…** downloads and verifies an update in the background with visible progress and a cancel button. Editing and navigation stay available. Once downloaded, **Install and restart** lets you save or discard pending changes, or cancel installation. Download completion alone never starts the installer.

Stalled downloads time out with a retryable error. Installing restores saved onboard bindings where available, otherwise original mappings, before restarting. Profiles and macros are retained.

## Documentation

The README now focuses on installation, everyday usage, compatibility, and recovery. Source setup and build instructions are in a separate development guide. This release also includes the tray readability and Redragon M990-WL DPI improvements from v0.1.12 and v0.1.13.

## Download and validation

Use **Check for updates**, or download **Neuron-Setup-0.1.14-x64.exe** and run it after quitting Neuron from the tray. No manual uninstall is needed. The installer is unsigned; **SHA256SUMS.txt** contains its checksum.

All 180 unit tests passed. Packaged onboard-save, DPI, workspace, Redragon, desktop, and idle/active shutdown smoke tests passed. The 302-case renderer layout check passed, including five repeat runs after an initial transient startup error that could not be reproduced. Native key injection was skipped because another app had foreground focus. Hardware configuration writes in these checks were simulated; physical unplug/power-cycle persistence remains unverified.
