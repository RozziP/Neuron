# Neuron v0.1.3

Identify connected mice more reliably, confirm their model in Devices, and keep hardware support issues up to date.

## Download and install

Download **Neuron-Setup-0.1.3-x64.exe**, quit Neuron from its tray menu, run the installer, and launch Neuron from the Start menu. Node.js and administrator access are not required. The installer is unsigned. `SHA256SUMS.txt` contains the installer checksum.

## Changes

- Added a Devices panel asking whether a suggested mouse model is correct. Confirm a candidate or enter a different brand/model; your answer survives restarts and is included in the hardware report.
- Confirmed models with an enabled driver for the exact USB connection can close their associated automatic GitHub support issue. The service independently checks support and the issue association. Unsupported receivers and manually maintained issues stay open.
- Expanded automatic reports with HID report capabilities, Windows device/driver descriptions, and matching mouse-software evidence. The initial software adapter detects Redragon/Compx configurations. New evidence reaches existing issues once, including devices reported by earlier versions.
- Added recognition and status display for the Compx `3554:F55D` receiver. Multiple HID collections appear as one receiver, and unavailable battery data is identified correctly.
- Preserved unfinished model corrections when background identification details arrive, and updated the displayed app version.

## Compatibility and reporting

Compx receiver recognition does **not** enable remapping, DPI, macros, or battery queries for the paired mouse. A shared receiver ID or installed-software match cannot prove a retail model. Hardware writes remain experimental and limited to Naga Trinity's supported 7- and 12-button plates.

Reports are public on GitHub. They exclude serial-number fields, device/filesystem paths, profiles, games, input events, complete configuration files, and unrelated installed software. Confirmed names are explicitly user-supplied evidence; confirmation does not enable an unverified driver. The updated reporting service is already deployed.

## Validation

All 73 automated tests passed. The release application passed the desktop UI smoke test and simulated DPI checks. The new report collector was verified against the connected Compx receiver, and enriched evidence was delivered to its existing issue without closing it. Issue-closure and retry behavior were tested with simulated GitHub responses. Native key injection was skipped when another application held foreground focus.
