# Neuron v0.1.10

Map the Naga V2 Pro's top buttons and adjust its current DPI over USB, its wireless receiver, or Mouse Dock Pro.

## Changes

- Added experimental remapping for the V2 Pro's **Scroll mode button (front)** and **DPI cycle button (rear)**. Existing assignments keep their button identities, and Restore original restores the saved native button actions.
- Added **100–30,000 DPI** control for Naga V2 Pro, with linked or independent horizontal and vertical sensitivity. Supported connections are wired USB, the USB wireless receiver, and Mouse Dock Pro after saving Naga V2 Pro as its paired mouse under Devices. Bluetooth configuration is not supported.
- The DPI screen now requires a successful hardware read before enabling changes. Unsupported devices and failed reads show an unknown current DPI instead of a default value. A failed refresh clears the previous reading.
- DPI changes are read back and checked, with original sensitivity backed up and rollback attempted if a write fails. Restore original supports V2 Pro sensitivity above 16,000 DPI.

DPI changes affect current sensitivity. This release does not rewrite the mouse's DPI-stage table or guarantee that sensitivity survives a power cycle. Applying button profiles leaves DPI unchanged.

## Download and upgrade

Use **Check for updates** in Neuron, or download **Neuron-Setup-0.1.10-x64.exe**, save pending edits, quit Neuron from its tray menu, and run the installer. Existing profiles, macros, mouse choices, and original-settings backups are retained. The installer is unsigned; **SHA256SUMS.txt** contains its checksum.

## Validation

All 136 automated tests and 302 renderer layout checks passed. Packaged desktop, DPI, and workspace smoke tests passed, including a simulated V2 Pro through Mouse Dock Pro, independent-axis changes, and failed-read handling. Tests cover top-button writes and restoration, DPI readback and rollback, and unsupported transports. Physical validation on a Naga V2 Pro and Mouse Dock Pro is still pending.
