# Neuron v0.1.2

First downloadable Windows x64 installer for Neuron, a local-first desktop control center for Razer Naga mice.

## Download and install

Download **Neuron-Setup-0.1.2-x64.exe**, run the installer, and open Neuron from the Start menu. Node.js and administrator access are not required. The installer is unsigned and Windows may show an unknown-publisher warning. `SHA256SUMS.txt` contains the installer checksum.

## Included

- Button rebinding, modifier shortcuts, a virtual keyboard tester, shared macros, and automatic game profiles.
- Macro playback once, a chosen number of times, toggled continuously, or while a button is held; a picker for assigning saved macros.
- Current X/Y DPI control for Naga Trinity, independent of button profiles.
- Battery percentage and charging status in the tray for supported wireless USB/receiver connections.
- Reliable window reopening from the tray and subsequent launches.
- Automatic sanitized unsupported-mouse hardware reports, with duplicate detection.

## Compatibility

Hardware writes are experimental and enabled only for Naga Trinity. Trinity's 12-button plate is the hardware-tested starting point; other plates and wireless battery reporting still need physical acceptance testing. Close Synapse before applying settings. Macros require Neuron to remain running.

## Validation

All 50 automated tests passed. The packaged application passed the desktop UI smoke test, native input and connected-mouse read checks, and the simulated DPI smoke test. Tray rendering checks passed. These checks do not establish universal Naga compatibility.
