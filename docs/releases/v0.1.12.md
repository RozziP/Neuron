# Neuron v0.1.12

The battery percentage and charge bar are easier to read at Windows system tray size.

- Larger white percentage numbers use nine pixels of height at the standard 16-pixel icon size, up from five. The full 100 reading fits without shrinking the digits.
- A thicker battery bar separates remaining capacity from the empty track. Empty, nearly full, and full charge remain distinct. Low battery stays orange and charging stays blue.
- Icons include native 16, 20, 24, 32, 40, 48, and 64-pixel versions for common Windows display scales.

Use **Check for updates**, or download **Neuron-Setup-0.1.12-x64.exe**, save pending edits, quit Neuron from its tray menu, and run the installer. Existing profiles and settings are retained. The installer is unsigned; **SHA256SUMS.txt** contains its checksum.

Validation: all 161 release tests passed. The native tray check verified eight battery states across all seven icon sizes, and the packaged desktop smoke test passed.
