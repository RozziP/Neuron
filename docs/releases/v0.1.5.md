# Neuron v0.1.5

Experimental remapping for more Naga models, Mouse Dock Pro support, and saved manual mouse selection.

## Download and upgrade

Download **Neuron-Setup-0.1.5-x64.exe**, quit Neuron from its tray menu, and run the installer. Existing installations are upgraded in the same folder, retaining profiles, shared macros, mouse selections, and original-mouse backups. The installer restores **Neuron** in the Windows Start menu on every install or update, even if its shortcut was deleted. No manual uninstall is needed.

Launch Neuron from the Start menu afterward. Node.js and administrator access are not required. The installer is unsigned. `SHA256SUMS.txt` contains its checksum.

## Changes

- Adds experimental remapping for Naga Pro, Naga V2 Pro, and Naga V3 Pro over wired USB and their receivers, with 2-, 6-, and 12-button plates.
- Adds experimental 12-button remapping for Naga V2 HyperSpeed.
- Recognizes Mouse Dock Pro (`1532:00A4`) and supports experimental V2/V3 Pro remapping and battery reads through it. A read-only query selects the paired model when possible; otherwise, Devices asks the user which mouse is paired.
- Adds manual model selection on Devices, including offline profile editing. Saves the preferred model and per-connection choices across restarts.
- Uses model-specific button addresses and storage layers. Preserves full native assignment data in backups, checks every changed mapping by reading it back, and rolls back failed applications.
- Extends automatic game-profile switching to the new adapters and prevents incompatible profile or driver choices from writing to a different mouse.
- Repairs missing Start menu shortcuts during both normal installer upgrades and NSIS update mode.

## Hardware status

The new adapters use published community protocol captures and remain **experimental**. They have not been physically verified in Neuron; Trinity retains its existing locally tested driver. Pro-family remaps use the live layer and may reset after a power cycle or onboard profile change. V2 HyperSpeed also updates its stored profile, with originals backed up for restoration.

Bluetooth configuration, older models without sufficient protocol evidence, additional V3-specific controls, and non-Trinity DPI controls remain unsupported. Close Synapse before applying mappings. See the repository's hardware notes for protocol evidence and limitations.

## Validation

All 92 automated tests passed, including simulated transport checks for exact restoration, lost acknowledgements, rollback, model/plate validation, dock identification, and game-profile selection. Desktop and simulated DPI smoke tests passed. The installed application passed both smoke tests. A real 0.1.4-to-0.1.5 upgrade preserved the install folder and saved settings, and restored a deliberately removed Start menu shortcut in both normal installer and NSIS update modes. Native key injection was skipped in the installed-app smoke run because another application held foreground focus.
