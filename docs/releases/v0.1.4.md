# Neuron v0.1.4

Find new Neuron releases from the app's sidebar.

## Download and upgrade

Download **Neuron-Setup-0.1.4-x64.exe**, quit Neuron from its tray menu, and run the installer. Existing installer-based installations are detected and upgraded in the same folder. No manual uninstall is needed; saved profiles, shared macros, and original-mouse backups are retained. Portable users can run the installer to switch to an installed copy.

Launch Neuron from the Start menu afterward. Node.js and administrator access are not required. The installer is unsigned. `SHA256SUMS.txt` contains its checksum.

## Changes

- Checks GitHub for a newer stable release at startup and every six hours.
- Adds **Check for updates** and an **Update to…** button that opens the release on GitHub for manual download and installation.
- Shows the running application's actual version in the sidebar.
- Handles offline checks, timeouts, and GitHub rate limits without interrupting mouse controls. A previously discovered update stays available during connection failures.
- Keeps update controls visible at the minimum window size.

## Validation

All 78 automated tests passed. Update availability, browser handoff, connection failures, and up-to-date responses were checked through Electron's actual renderer/main-process boundary using simulated releases. The release application passed the desktop UI and simulated DPI smoke tests. A real 0.1.3 to 0.1.4 installer upgrade was checked for folder reuse, registration replacement, and preservation of profiles, macros, and backups. Native key injection is skipped when another application holds foreground focus.
