# Neuron v0.1.13

Redragon M990-WL now has experimental DPI controls. Select the mouse, open **DPI**, and use **Read DPI** before applying changes.

- Adjust horizontal and vertical sensitivity independently or together from 50 to 26,000 DPI, in steps of 50.
- Changes are saved to the active onboard DPI stage. Other stages, colors, and button mappings stay unchanged. Read DPI again after using the mouse's DPI or onboard-profile buttons.
- Each changed stage's original value is backed up. Writes are checked after reload, failures attempt rollback, and **Devices → Restore original** restores the backed-up stages.
- Neuron verifies the connected M990-WL's model identity before allowing changes. Shared receiver IDs do not enable this driver for other Redragon mice.

The wireless connection was physically tested by changing X from 2,650 to 2,700 DPI, verifying readback, then restoring 2,650 DPI on both axes. The original settings and button mappings were verified unchanged afterward. Wired USB remains experimental and has not been physically tested. Bluetooth configuration, top-button remapping, measured cursor accuracy, and power-cycle persistence are not covered by this validation. Keep the mouse awake and close Redragon's configuration software while applying.

Use **Check for updates**, or download **Neuron-Setup-0.1.13-x64.exe**, save pending edits, quit Neuron from its tray menu, and run the installer. Existing profiles and settings are retained. The installer is unsigned; **SHA256SUMS.txt** contains its checksum.

Validation: all 169 release tests passed. Packaged Redragon and Naga DPI UI checks and the desktop smoke test passed. Native keyboard injection was skipped because another app held foreground focus. This release also retains the tray readability improvements from v0.1.12.
