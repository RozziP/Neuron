# Neuron v0.1.11

DPI control now covers the modern Naga lineup, with each model's own range and write behavior.

## Supported DPI ranges

| Mouse | DPI range | Connections |
| --- | --- | --- |
| Naga Trinity | 100–16,000 | USB |
| Naga X | 100–18,000 | USB |
| Naga Left-Handed Edition 2020 | 100–20,000 | USB |
| Naga Pro | 100–20,000 | USB or its receiver |
| Naga V2 HyperSpeed | 100–30,000 | Its receiver |
| Naga V2 Pro | 100–30,000 | USB, its receiver, or identified Mouse Dock Pro |
| Naga V3 Pro | 100–50,000 | USB, its receiver, or identified Mouse Dock Pro |

Open **DPI**, read the mouse, and apply linked or independent X/Y sensitivity. Apply remains disabled until a read succeeds. Writes are read back and checked, originals are backed up, and failures trigger rollback. Failed reads show unknown sensitivity instead of a default value.

Pro, X, Left-Handed 2020, and V2 HyperSpeed use their documented stored sensitivity write. Neuron does not edit the separate DPI-stage table or guarantee persistence across power cycles. Applying button profiles leaves DPI unchanged.

## Buttons and compatibility

Existing model-specific top and body-button mappings now have additional write, restoration, and rollback coverage, including the V3 Pro's index, pinky, scroll, and profile buttons. The Left-Handed 2020 underside profile button is listed as a hardware control; its remapping remains unavailable because its protocol source is not established.

Mouse Dock Pro support remains limited to compatible V2/V3 Pro identities. Select the correct paired mouse under Devices when automatic identification is unavailable. Bluetooth configuration and older Naga models are outside this DPI expansion.

## Download and validation

Use **Check for updates**, or download **Neuron-Setup-0.1.11-x64.exe**, save pending edits, quit Neuron from the tray menu, and run the installer. Profiles, macros, mouse choices, and backups are retained. The installer is unsigned; **SHA256SUMS.txt** contains its checksum.

All 160 release tests and 302 renderer layout checks passed. Packaged DPI, workspace, and desktop smoke tests passed. DPI tests use simulated devices and cover model limits, write storage, independent axes, malformed reads, failed writes, and restoration. Physical verification of the expanded models and V3 dock passthrough remains pending; this support is experimental.
