# Neuron v0.1.9

Choose what happens to unsaved edits before updating, and see the Naga V2 Pro's six-button panel in its physical order.

## Changes

- Starting an update with unsaved profile or macro edits now offers **Save and update**, **Discard**, and **Cancel**. Saving validates and persists the edits before downloading. Discarding restores the saved versions and continues. Canceling or dismissing the prompt keeps the edits and does not start the download. Updates with no pending edits continue directly.
- The Naga V2 Pro's six-button panel now displays **1–2–3** across the top and **6–5–4** across the bottom, matching the mouse. Existing assignments remain attached to their numbered buttons. This applies to V2 Pro workspaces for wired, wireless, Bluetooth, and dock connections; hardware support is unchanged.

## Download and upgrade

Use **Check for updates** in an installed Neuron v0.1.7 or later, or download **Neuron-Setup-0.1.9-x64.exe**, save pending edits, quit Neuron from its tray menu, and run the installer. Existing profiles, macros, mouse selections, and original-mapping backups are retained. The installer is unsigned; **SHA256SUMS.txt** contains its checksum.

The new unsaved-changes prompt takes effect once v0.1.9 is installed. Updating from an older version still uses that version's update flow.

## Validation

All 125 automated tests and 302 renderer layout checks passed. The packaged desktop smoke test passed, covering save, discard, cancel, dialog dismissal, invalid edits, and updates without pending edits. Update downloads and installation were simulated during the smoke test.
