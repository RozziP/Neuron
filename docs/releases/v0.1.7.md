# Neuron v0.1.7

Install future updates directly from Neuron, and quit cleanly without leaving background processes running.

## Download and upgrade

Download **Neuron-Setup-0.1.7-x64.exe**, save any pending edits, quit Neuron from its tray menu, and run the installer. Existing installations retain saved profiles, macros, mouse selections, and original-mouse backups. Launch Neuron from the Start menu afterward. No manual uninstall, Node.js installation, or administrator access is needed.

Version 0.1.6 and earlier need this one manual upgrade to receive the new in-app updater. The installer is unsigned; `SHA256SUMS.txt` contains its checksum.

## Changes

- Clicking **Update to…** now saves pending edits, downloads the Windows installer with progress, checks its size and SHA-256 digest against GitHub release metadata, restores active mouse mappings, and installs and restarts Neuron. Invalid edits stop the update so they can be corrected first.
- Download failures can be retried without quitting. Installer failures are recorded and reported when Neuron reopens. Checking for updates does not install them automatically.
- Quitting from the tray now waits for mapping restoration and native helper cleanup, stops background discovery processes, and exits the application completely. Updates use the same shutdown path. Closing the window still keeps Neuron in the tray.

## Availability and limitations

Automatic installation is available for installed Windows builds; development and portable copies require manual updates. Download integrity checks use GitHub release metadata and do not replace publisher signing. Existing experimental hardware support and limitations are unchanged; see the README for device details.

## Validation

All 120 automated tests passed, including download integrity and native updater handoff checks. Packaged desktop and updater smoke checks passed. Both idle and simulated active-profile shutdown tests left zero background processes; these checks made no physical hardware writes. Native key injection was skipped when another application held foreground focus. The local upgrade preserved all 12 saved JSON files and installed the tested application archive.
